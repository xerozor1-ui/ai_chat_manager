# AI Chat Manager

A command-line application for managing AI chat sessions with automatic tag suggestion.

## Overview

This project is being developed as part of the Python & AI Fundamentals course. It will evolve from a simple command-line organizer into an intelligent application that uses machine learning to suggest tags for chat sessions.

## Features (Planned)

- Store chat sessions with names, dates, and topics
- List all stored sessions
- Search sessions by keyword
- Save and load sessions from files
- Automatic tag suggestion using ML (Week 12)
- Web interface (Course 2)
- AI agents and RAG integration (Course 3)

## Environment Setup

- Python: 3.11
- Environment: chat_manager (conda)
- Editor: VS Code
